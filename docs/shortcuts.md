# Keyboard shortcuts (Jotdex 1.3.0)

App-wide:

| Shortcut | Action |
|---|---|
| `Ctrl+K` | Search |
| `Ctrl+O` / `Ctrl+P` | Quick open |
| `Ctrl+N` | New note |
| `Ctrl+S` | Save now |
| `Ctrl+F` | Find in note |
| `Ctrl+Shift+V` | Paste as plain text |

Editor (visual mode):

| Shortcut | Action |
|---|---|
| `/` at the start of a block | Slash command menu |
| **Insert** (toolbar) or gutter **+** | Same command list as slash |
| Long-press the note (touch) | Opens the insert menu |
| `Alt+ArrowUp` / `Alt+ArrowDown` | Move the current block |
| Selection + bubble **More** | Highlight, underline, sub, sup, clear |
| `[[` | Link to another note |

On a phone or narrow window, **Insert** and **↑/↓** stay visible (they do not depend on hover). Gap-cursor **+** still appears between stacked hard blocks on desktop.
